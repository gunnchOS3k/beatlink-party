# Game Design Document — BeatLink Party

## Working Title: BeatLink Party

## 1. High Concept

BeatLink Party is a rhythm, karaoke, and music-party game where one host launches a session on a TV, laptop, tablet, or projector, and players join from their own phones using a room code. The host pastes a YouTube, Spotify, Apple Music, or approved audio link, and the game turns that song into a multiplayer party challenge with rhythm tapping, karaoke prompts, crowd callouts, team battles, and performance scoring.

## 2. Core Fantasy

Players feel like they are at a living-room concert where every phone becomes an instrument, microphone, hype button, or crowd controller.

## 3. Design Pillars

- **Instant Party** — minimal setup to start a room
- **No Controller Barrier** — phones in browser only
- **Music Link Magic** — link identification and catalog matching (compliance-safe)
- **Everyone Has a Role** — vocalist, drummer, hype, crowd, etc.
- **Skill + Chaos** — timing rewards plus party prompts and crowd voting

## 4. Target Audience

Friends at parties, families, dorm rooms, streamers, karaoke fans, rhythm-game fans, casual players without controllers.

## 5. Player Count

- MVP: 1 host, 2–6 active phone players
- Future: 100+ crowd mode for events

## 6. Core Game Loop

1. Host starts room → players join → host selects song → roles assigned → countdown → gameplay → results → replay

## 7. Music Input Model

1. Approved Catalog Mode (MVP primary path)
2. Creator Upload Mode
3. Link Match Mode (metadata + catalog match)
4. Authorized Playback Mode (future, platform-licensed)

## 8. Music Compliance Rule

The game must not rip audio from YouTube, Spotify, or Apple Music. "Upload a link" means identification, metadata, playback authorization, or catalog matching — not download.

## 9. Game Modes

MVP: Beat Battle, Karaoke Prompt, Hype Squad

Future: Band Room, Team Versus, Call & Response, Freestyle Break, Streamer Mode

## 10. Player Roles (MVP)

- **Vocalist** — phrase prompts on cue
- **Beat Tapper** — rhythm taps
- **Hype Captain** — crowd boosts and emotes

## 11. Scoring

Timing accuracy, streaks, role completion, crowd energy, fun awards (MVP, Best Vocalist, Best Beat, Best Hype, etc.)

## 12. Visual Style

Bold concert aesthetic: neon stage lighting, big readable lyrics, animated equalizers, couch-readable host UI.

## 13. MVP Scope

Host room, phone join, approved test songs, 3 roles, rhythm scoring, basic karaoke prompts, results, replay, metadata-only link paste.

## 14. Long-Term Vision

Creator uploads, licensed packs, community beatmaps, AI beatmap generation, classroom/event mode, tournaments.
