# Roadmap — BeatLink Party

## Phase 1: Core Party Prototype ✅ (MVP)

- Host room creation, phone join, real-time input
- Approved test songs, simple beatmaps, tap timing, score screen

## Phase 2: Roles and Results ✅ (MVP)

- Vocalist, Beat Tapper, Hype Captain roles
- Player awards, team score, replay flow

## Phase 3: Music Pipeline

- User audio upload with rights attestation
- BPM detection and beat grid generation
- Manual beat correction UI
- Enhanced link resolver with OAuth metadata APIs (still no ripping)

## Phase 4: Compliance-Safe Link Mode

- YouTube/Spotify/Apple official metadata APIs where permitted
- Internal catalog fuzzy matching
- Fallback UI polish
- Catalog search

## Phase 5: Creator Tools

- Creator upload dashboard
- Beatmap editor (tap-to-place, drag timing)
- Lyrics editor for owned/public-domain lyrics
- Publish flow with license checklist

## Phase 6: Production Hardening

- Redis room persistence
- PostgreSQL for songs, sessions, users
- Latency calibration UI
- Reconnect hardening across host refresh
- Rate limiting and upload scanning

## Phase 7: Advanced Game Modes

- Band Room, Team Versus, Call & Response
- Freestyle Break, Streamer Crowd Mode
- Tournament and event modes

## Phase 8: Commercial Release

- Licensed music packs
- Lyric provider integration
- Platform playback SDKs (where licensed)
- DMCA and creator rights workflows
